# APEX_T_JAVASCRIPT_OBJECT (APEX 26.1 PL/SQL API, texto extraído del PDF oficial, líneas 62254-63385)

APEX_T_JAVASCRIPT_OBJECT

                       The APEX_T_JAVASCRIPT_OBJECT object type is a utility for constructing JavaScript objects to be
                       passed onto the browser. Note that this object type does not construct JSON, but JavaScript
                       objects, with support for unescaped properties like functions.

                       To construct JSON objects, use native database functionalities like sys.json_object_t
                       instead.

                       can be a function body, in which case it is wrapped with function(){}, or be an expression,
                       which case it is wrapped and the expression returned.
